# Calibur batching and quiet chat

The owner requested: “go for Calibur batching. I was just curious if 7702/Calibur also helps with usdg gas but Calibur most important still”. During implementation, they added: “we also shouldn't notify the chat on a rebalance ... it should be done in the daemon state and chat should read it as needed and not trust its own previous numbers ... we can disable notifications for now for cleanliness there and can do notifications more properly later”.

Implement a scoped, opt-in Ledger execution mode using Uniswap's canonical Calibur deployment on Robinhood chain 4663. Keep the same wallet and physical Ledger ownership. Batch each deficient exact ERC20 approval and the existing minimum-funded, ordered Uniswap multicall into one atomic self-call. Retain the direct path for existing configurations. No session keys, new contracts, hosted relayer, paymaster or USDG gas-payment setup is included.

The first self-funded EIP-7702 transaction uses an authorization for chain 4663, the pinned implementation and outer nonce plus one. The backend independently verifies the authorization and transaction signers. Later transactions read the exact existing delegation and need only the transaction signature. Reject foreign delegation or implementation-bytecode changes; never replace them automatically. Simulation must execute the entire call batch, including approvals. Before first authorization, use the exact delegation state override and account for the additional authorization gas cost without disclosing a reusable signed authorization to an estimation service. Preserve fee/native-balance checks, fresh quotes, Stop/settings/cadence barriers and pending-before-broadcast journaling. A failed execution can leave the delegation installed, so do not confuse a reverted batch with revocation.

Parallel subtasks: canonical source/deployment reproduction and pure calldata helpers; official Ledger SDK authorization/typed transaction integration; independent transaction/notification review. All tests use the isolated launcher or a disposable local EVM. Source compilation, fixtures and RPC simulations are distinct from physical device validation and mined Calibur transactions. Do not use live funds or replace a running process as a test fixture.

Persist a separate project-wide pause for portfolio chat notifications. Gate Codex, OpenCode and Claude event delivery and automatic selected-wallet notification setup; keep wallet setup and selection controls separate. Stop the existing notification-only worker. Retain daemon events, delivery history and uncertainty barriers. Do not create a polling model task or acknowledge events just to suppress them. Chat reads fresh intended-wallet daemon state on demand; prior conversation balances and completion claims remain historical. The owner may explicitly resume notifications later.
